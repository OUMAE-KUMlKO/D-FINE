# 15526 四边平均误差评测（2026-09-29）

15526 的四边平均误差为 **1.5992 输入像素**，相对早期 B0 的 **1.7028** 降低 **6.09%**；平均匹配 IoU 从 **0.79631** 提高到 **0.80178**。整体四条边均改善，小目标改善 7.01%，中等目标略有退化。

## 指标与权重

沿用早期 GT-strip 的 `GTRefinementMetrics`：对匹配 GT 的预测框计算左、上、右、下边界的绝对误差，对四边及全部目标等权平均。

`mean_edge_mae_px = sum(|L-Lgt| + |T-Tgt| + |R-Rgt| + |B-Bgt|) / (4*N)`

- 坐标系：640×640 网络输入像素，非原图像素。
- 数据：UAVSwarm `val_half.json` 全部 3394 张图、24265 个 GT。
- 图像目录：`/cluster/home/zzy/dataset/UAVSwarm-dataset-master/train/`。
- 标注：`/cluster/home/zzy/dataset/UAVSwarm-dataset-master/annotations/val_half.json`。
- B0：`/cluster/home/zzy/D-FINE/output/uavswarm_strip_20260923/b0/best_stg2.pth`。
- G5/15526：`/cluster/home/zzy/D-FINE/output/uavswarm_strip_beststg2_20260923/all_layer_band2d_query_gate_full/best_stg2.pth`。
- 两者严格加载 `ema.module`，FP32 推理，模型前向不传 GT。
- 两模型各自 Hungarian 匹配，再按同一个 GT 对齐；不同模型的 query 编号没有直接对应关系。
- 匹配成本：class=2、bbox=5、GIoU=2，focal alpha=0.25、gamma=2。无置信度/IoU 阈值，无边界裁剪。
- 两模型均匹配全部 24265 个 GT，公共 GT 数也是 24265；忽略 GT、无效统计对均为 0。
- 尺寸分组按 GT 在输入坐标的面积：small < 32²，medium [32²,96²)，large ≥ 96²。
