# UAVSwarm / VisDrone 规范对比实验方案

日期：2026-09-26。本文仅制定实验分组与统一口径，暂不修改训练代码或提交作业。

## 1. 目标

在相同训练预算和固定随机种子条件下，对比当前方案相对 D-FINE B0 的收益、检查能否在 VisDrone 上复现，并区分采样带、二维编码、概率输入和 query 融合方式的贡献。每个数据集的每组实验只训练一次。已有提升作为研究依据保留，正式结果使用新批次的统一对照。

## 2. 对比组

两个数据集均采用以下分组；所有改进组均在六层 decoder 中修正原 logits，推理不使用 GT。

| 组别 | 模型 / 采样 | 局部空间卷积 | MLP 的 log 概率输入 | query 融合 | 回答的问题 |
| --- | --- | --- | --- | --- | --- |
| G0 | 原始 D-FINE B0 | — | — | 原始结构 | 公平基线 |
| G1 | 每候选 `5×3`，法向 ±1 输入像素 | DW `3×1` | 有 | 拼接 | 全层候选边界分支的整体作用 |
| G2 | 每候选 `5×7`，法向 ±8 输入像素 | DW `3×1` | 有 | 拼接 | G2−G1：更宽、更密的采样带 |
| G3 | 同 G2 | DW `3×3` | 有 | 拼接 | G3−G2：二维局部编码 |
| G4 | 同 G2 | DW `3×3` | 无 | 拼接 | G4−G3：移除直接 log 概率输入 |
| G5 | 同 G2 | DW `3×3` | 无 | 通道调制 | G5−G4：query 调制；G5−G0：最终方案收益 |

**G5 对应已完成的作业 `15526`，是目前 UAVSwarm 预测引导实验中 AP 和 AP75 最好的版本**：AP **61.0662**、AP75 **67.5865**，同一 checkpoint 的 APsmall 为 **59.7663**。这不表示每个单项指标均最高；VisDrone 上的表现尚待本批实验验证。

G1–G5 保留相同的 pointwise `1×1`、64 维候选特征及原 logits 残差。G2 将带宽和点数作为一个采样设计整体，不单独归因于其中某一项；上述顺序消融说明条件性贡献，不等同于完整的组件交互实验。GT 引导结果作为诊断参考，不混入常规预测结果排名。

| UAVSwarm | `/cluster/home/zzy/dataset/UAVSwarm-dataset-master/train`；标注使用同数据集 `annotations/train_half.json` / `val_half.json` | 1 类，保持现有互斥划分与类别映射 |

VisDrone 标注使用根目录下的 `instances_UAVtrain_v1.json` / `instances_UAVval_v1.json`，已确认类别连续编号为 0–9，编号 0 是正常类别 pedestrian。执行前核验图像与标注对应关系，并对照原始 annotations 固定忽略区域处理；现有 JSON 未提供有效 ignore/crowd 标记。两个模型必须使用同一份处理后的标注。

主结果统一报告本地 COCO 格式验证集指标，固定类别映射、评测脚本和 `maxDets=100`；这些结果不直接等同于 VisDrone 官方评测口径。验证集不加入训练集，结果明确标注为验证集结果。

## 4. 公平性与随机性控制

- **统一使用 `seed=0`，每组只训练一次。** 固定公共检测器的初始化，并独立固定数据采样/增强随机源，避免新增模块消耗随机数改变数据流。
- **全部从 backbone 预训练开始。** 统一使用 `weight/hgnetv2/PPHGNetV2_B4_stage1.pth`；encoder、decoder、新分支重新初始化，按同一冻结规则联合训练，不加载旧实验检测器权重。
- **每个数据集内部统一训练预算。** 默认 80 epoch、8 GPU、全局 batch 64、基础输入 640；学习率、增强、多尺度、EMA、DN、原生损失及评测频率一致。若 VisDrone 显存不足，在正式实验前统一下调该数据集所有组的 batch。
- **统一训练器与选权重规则。** 开始前修正已知回载后的 epoch 计数偏移，保留同一套阶段切换/EMA 回载策略，并冻结代码和配置版本。所有组均按验证 AP 选择最佳 EMA 权重，同时保存末轮结果；不同模型可能在不同轮次触发回载，应一并记录。
- **不混用历史结果。** 旧 B0 的 batch 128、未完成第二阶段的实验及已有探索结果仅作历史参考，不替代统一设置下的新对照。

## 5. 执行顺序与报告

1. **优先主对照：G0、G5 × 两个数据集 × 1 个种子，共 4 次全量训练。** 先回答总体收益与跨数据集复现问题。
2. **补齐归因：G1–G4 × 两个数据集 × 1 个种子，共 8 次。** 完整矩阵总计 **12 次**。已有代码覆盖 G0、G1、G3、G4、G5，G2 主要通过配置构建。
3. 每个数据集分别报告单次训练的 AP、AP50、AP75、APsmall，并报告 G5−G0 及相邻消融组的差值（单位：百分点）。以 AP 为主指标，AP75 和小目标指标解释收益，同时列出退化项。
4. 最佳 AP 对应的其他指标来自同一 checkpoint；末轮和阶段曲线作为辅助。本轮为固定种子的受控对比，不报告跨种子均值或标准差，不据此声称统计显著性。
5. 为 G0、G5 补充参数量、同 GPU / 640 输入 / batch 1 下的推理时延及峰值显存，明确精度收益的计算代价。

本批不同时加入新的候选交互模块，先完成当前方案的规范验证与归因。
