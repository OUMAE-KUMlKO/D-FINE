# 面向小目标高精度检测的边界证据驱动分布细化

日期：2026-09-20  
文档性质：研究方案草案；方法尚未实现，预期收益尚未通过实验验证。

## 1. 研究目标与结论来源

本研究的主线是：**提高小目标检测精度，重点解决已经大致找到目标、但框仍不够准确的问题。** 标注误差是定位困难的一个来源，不作为论文的中心问题，也不要求先建立标注去噪系统。

建议采用 D-FINE 作为方法载体，研究如下机制：

> 为同一条边保留多个候选位置，在每个候选位置及其两侧提取局部图像特征，再用这些特征修正对应位置的概率，使检测框能够更准确地贴合目标范围。

全文区分三类信息，避免把推测写成已有结论。

| 信息类型 | 本文中的具体内容 | 应如何理解 |
| --- | --- | --- |
| 用户已有观察 | 在 UAVSwarm 上测试过的模型，AP50 达到九十几，而 AP75 只有四十几 | 这是用户报告的近似结果。本文没有重新核验日志，也不将这组数值归属于尚未明确的具体模型或配置 |
| 已有论文事实 | D-FINE 使用四边离散分布并逐层细化；SABL、BorderDet、LocNet 等已有空间定位或边界特征机制 | 相关说明附原始论文链接 |
| 本方案提出的假设 | 给每个候选边界增加与其位置对应的局部特征，可以改善候选辨别和高 IoU 定位 | **这是讨论中提出的研究假设，不是 D-FINE 论文的假设或结论** |

目前没有证据证明：D-FINE 缺少边界信息、候选辨别不足就是上述 AP75 偏低的主要原因，或者本方案一定优于现有方法。后续实验需要逐项回答这些问题。

建议优先阅读第 2 节理解问题、第 5 节理解方法、第 6 节了解已有研究和差异、第 7 节了解验证方式。

## 2. 为什么把重点放在高精度定位

### 2.1 AP50 很高、AP75 明显下降说明什么

AP50 和 AP75 分别在 IoU 阈值为 0.50 和 0.75 时计算平均精度。常见的 AP@[.5:.95] 则是在 0.50、0.55、……、0.95 共十个阈值上取平均，不能与 AP50 混用。

用户的观察说明：模型在较宽松的框重叠要求下表现很好，但在较严格的要求下仍有很大提升空间。这为研究高精度定位提供了直接动机。

不过，AP 同时受框坐标、置信度排序、重复检测、漏检和匹配关系影响。AP50 与 AP75 的差距本身不能定量证明所有损失都来自框坐标，更不能直接归因于某个特征模块。补充一次基于现有预测的轻量诊断即可，不需要先开展大规模标注审查。

### 2.2 一个像素为什么可能决定检测是否成功

考虑两个边长都为 \(s\) 的正方形框，只沿水平方向平移 \(d\)，且 \(0\leq d<s\)。它们的交集面积为 \((s-d)s\)，并集面积为 \((s+d)s\)，因此：

\[
\mathrm{IoU}=\frac{s-d}{s+d}.
\]

| 目标大小 | 水平平移 | IoU |
| --- | --- | --- |
| 50 × 50 像素 | 2 像素 | 约 0.923 |
| 5 × 5 像素 | 2 像素 | 约 0.429 |
| 5 × 5 像素 | 1 像素 | 约 0.667 |

要求 IoU 不低于阈值 \(t\)，可得到：

\[
d\leq s\frac{1-t}{1+t}.
\]

对 5 像素宽的目标，通过 IoU 0.50 允许约 1.67 像素的平移；通过 IoU 0.75 只允许约 0.71 像素。因此，同一个预测框可能通过 AP50 的定位要求，却无法通过 AP75 的要求。

这个推导只针对等尺寸框的单方向平移，不是任意框误差的统一界限。实际预测还包含宽高变化、两轴平移和不同边的组合误差。

### 2.3 本研究考虑的定位困难

| 困难 | 通俗解释 | 在本方案中的位置 |
| --- | --- | --- |
| 几何敏感性 | 同样的像素误差对小目标更严重 | 决定研究目标应包含高 IoU 指标 |
| 空间细节不足 | 下采样后，几个相邻边界位置可能对应非常相似的特征 | 需要检验现有特征是否支持精细辨别 |
| 背景与邻近目标干扰 | 取样位置稍有变化，混入的信息就可能不同 | 研究候选边界及其两侧的局部证据 |
| 模糊、遮挡和成像噪声 | 图像本身不能清楚说明边界在哪里 | 保留候选竞争，不强制分布无条件变尖 |
| 标注误差 | 监督框也可能存在偏差 | 作为影响因素和可选鲁棒性分析，不作为主任务 |

这些是需要考虑的机制，不代表已经在 UAVSwarm 上逐项证实。

## 3. 如何保留最初关于非对称性的想法

原始想法中有价值的一点是：**把框向外扩张和向内收缩，接触到的图像信息往往不同。** 本方案保留这一点，但把它落实到候选位置的特征辨别中。

需要区分三个概念：

1. **误差偏置：** 某个方向的误差更常见。例如，标注框可能经常偏大。这需要统计证据，不能作为通用事实。
2. **分布形状：** 去掉平均偏差后，两侧的概率形状是否仍然不同。外扩更常见，也可能只是一个均值偏移的对称分布，并不必然要求偏态分布。
3. **误差代价：** 扩张和收缩对特征提取或下游任务的影响是否不同。代价不对称不能直接证明概率分布不对称。

因此，本方案不预设框应偏大、偏小或符合某种固定偏态分布。它允许不同候选根据各自的图像证据获得不同修正，最终分布可以对称，也可以非对称。

还需要注意：**检测框边界不等于物体轮廓。** 无人机外形不规则，框的某些边段可能没有清晰前景；框内也可能包含大量背景。内侧、边上、外侧在本文中只是几何位置，不是人工定义的前景或背景标签。

## 4. D-FINE 已经提供了什么，本方案还想研究什么

### 4.1 D-FINE 的基础机制

[D-FINE（ICLR 2025；预印本发布于 2024 年）](https://arxiv.org/html/2410.13842v1)为四条边建立离散偏移分布，通过 FDR 逐层更新分布，并通过 GO-LSD 在不同解码层之间传递定位知识。

可以把一条边的输出理解为：模型给若干候选位置分配权重，再对位置求加权平均。实际实现使用非均匀候选偏移，并通过参考框和尺度映射到图像坐标。

它不是高斯框模型，也不要求分布对称。其解码器已经通过注意力利用空间特征。不能据此把现有方法描述为“完全不看边界”或“完全不利用局部信息”。

两个容易误解的地方是：

- 离散分布的期望可以产生连续坐标，bin 数量不等于最终输出只能落在若干整数像素上。
- softmax 权重可以用于候选比较，但未经校准不能直接解释为真实边界的可信概率、标注噪声大小或可靠的置信区间。

### 4.2 本方案的三个可检验假设

**H1：候选对应的局部证据有用。** 对同一条边的多个候选位置分别提取特征，可能比只用汇总特征预测整组概率，更有利于辨别相近位置。

**H2：保持对应关系有用。** 候选 \(k\) 的证据直接用于修正候选 \(k\) 的 logit，可能比把所有候选特征合并成一个向量更有效。

**H3：边界两侧的证据有额外价值。** 在候选边界线上取特征之外，同时观察其内侧和外侧，可能帮助判断该边应继续扩张还是收缩。

这三个假设均由本方案提出。其合理性需要第 7 节的对照实验支持，而不是通过引用 D-FINE 来证明。

### 4.3 为什么选择这条路线

| 可选路线 | 优点 | 局限与安排 |
| --- | --- | --- |
| 调整定位损失或增加精细化训练权重 | 实现简单，适合作为强对照 | 不能单凭损失加权就认定解决了边界证据不足 |
| 候选边界取证，再更新分布 | 直接检验相邻候选的空间辨别问题，适合接入 D-FINE | 本文推荐的主线；需要证明优于已有边界采样 |
| 建立四边联合分布或更复杂的生成模型 | 可以研究边之间的相关性和复杂形状 | 变量较多，初版不同时引入，以便识别主机制的作用 |

## 5. 方法设计：让候选边界带着证据竞争

### 5.1 整体流程

```text
图像 → 原有骨干与解码器 → 末层四边 logits
                              │
                              ├─ 原有映射 → 各 bin 对应的候选边界位置
                              │                    │
                              │              内侧／边上／外侧采样
                              │                    │
                              └────── 逐候选证据修正 logits
                                                   │
                                          原有期望解码 → 检测框
```

初版只在末层增加一次证据修正。这样可以先回答：相同的检测器、相同的原始分布，通过额外的空间取证能否得到更准确的框。机制成立后，再考虑推广到多层。

### 5.2 先明确候选位置，不能把 bin 当成固定像素

设 \(z_{j,k}\) 是原末层输出，其中 \(j\) 表示左、上、右、下四条边，\(k\) 表示离散候选。对应权重为：

\[
p_j(k)=\operatorname{softmax}_k(z_{j,k}).
\]

记 \(\mathcal D_j\) 为原实现中，从参考框、尺度和候选偏移到第 \(j\) 条边图像坐标的映射，则：

\[
c_{j,k}=\mathcal D_j(b_{\mathrm{ref}},v_k),
\]

其中 \(v_k\) 是该 bin 对应的偏移支持值。这里的 \(\mathcal D_j\) 是对现有坐标变换的记号，不是另一个待学习模型。

必须满足：用于取特征的 \(c_{j,k}\)，与最终解码时第 \(k\) 个 bin 的含义一致。仅仅保持 bin 数量相同还不够，参考框、尺度和坐标映射也必须一致。

因此，初版直接使用**同一末层、同一原始参考信息、同一组支持值**构造候选和解码；不额外改变搜索范围，不在更新过程中重定义 bin 的物理含义。

### 5.3 如何在候选边界附近采样

先从原分布解码出当前框。对一条候选边界，用当前框其余方向的范围确定这条边的采样跨度。例如，右边界候选是一个横坐标，其纵向范围取当前框的上、下边界。

沿这条候选边线选取少量位置，再在每个位置沿法线方向采样三组特征：

- **内侧特征：** 朝当前框内部移动一小段距离后采样。
- **边上特征：** 在候选边界位置采样。
- **外侧特征：** 朝当前框外部移动一小段距离后采样。

以右边界为例，内侧在左，外侧在右；左边界则相反。上、下边界也需要相应改变方向。

可以先沿边使用 3 个采样位置，三组位置共 9 个点，分别聚合得到：

\[
f^{\mathrm{in}}_{j,k},\quad f^{\mathrm{edge}}_{j,k},\quad f^{\mathrm{out}}_{j,k}.
\]

采样间距用网络输入图像上的像素单位定义，再按所用特征层的步长转换。图像缩放、坐标归一化和采样算子的约定必须一致。图外采样点使用有效性标记；没有有效证据时，不应把填充值解释为背景证据。

**为什么取条带而不是只找清晰轮廓？** 小目标边缘可能模糊，而且框边界并不处处经过前景。沿边的多个局部位置能够提供不同线索，再结合目标 query 判断这些线索是否属于当前目标。

**为什么双线性采样不等于恢复了细节？** 它可以在连续位置插值，但无法凭空恢复骨干下采样已经丢失的信息。如果两个候选在所用特征图上几乎不可区分，本模块也可能没有足够信息完成判断。这是需要实验检验的限制。

### 5.4 如何把证据变成概率修正

将每个候选自己的三组特征与目标 query \(q\)、边方向及候选位置编码输入共享的小网络：

\[
\Delta z_{j,k}
=g\left(f^{\mathrm{in}}_{j,k},f^{\mathrm{edge}}_{j,k},
f^{\mathrm{out}}_{j,k},q,\mathrm{pos}_{j,k}\right),
\]

\[
z'_{j,k}=z_{j,k}+\Delta z_{j,k},\qquad
p'_j(k)=\operatorname{softmax}_k(z'_{j,k}).
\]

这里的 logit 可以理解为 softmax 之前的候选得分。小网络输出一个得分修正量，决定当前证据应该提高还是降低该候选的竞争力。

关键关系是：

\[
\boxed{\text{候选 }k\text{ 的实际位置}
\longrightarrow \text{该位置的证据}
\longrightarrow \text{候选 }k\text{ 的得分修正}}
\]

更新公式本身沿用残差思想，不能作为独立创新。拟研究的是更新量从哪里来，以及候选与图像证据的对应关系是否有价值。

虽然这个形式看起来像“先验乘以证据后再归一化”，初版不把它解释为严格的贝叶斯后验更新。原分布和新增特征来自同一图像，证据的独立性及概率校准都没有得到证明。

### 5.5 一个说明性例子

假设右边界有三个候选横坐标：100、100.5、101 像素，原权重为 0.30、0.40、0.30，原期望坐标为 100.5。

经过各自位置的取证后，权重变成 0.10、0.25、0.65，期望坐标变为：

\[
100\times0.10+100.5\times0.25+101\times0.65=100.775.
\]

如果目标边界确实更接近 101，这次更新可能有益；若局部背景产生了误导，它也可能变差。这个例子只解释计算方式，不代表实验结果，也不表示高概率候选一定正确。

它同时说明：即使候选位置有限，期望解码仍可得到连续坐标。增加 bin 数量和获得更可靠的证据是两个不同问题。

### 5.6 完整候选与稀疏候选应分开研究

**首版：完整候选取证。** 对原有各 bin 都计算证据修正，支持值不变。这样最容易判断机制是否有效，也不会由于提前筛选而遗漏原来低概率的正确候选。准确名称是“候选边界条件取证”。

**后续：概率指导的稀疏取证。** 在完整版本有效后，再依据当前分布选择候选。只有当概率实际影响候选选择、采样预算或取证范围时，才应称为“概率引导采样”。

稀疏版本必须说明未选 bin 如何处理。最简单的规则是未选 bin 的修正量为零，再对所有 logits 统一归一化；不要未经说明直接删除其概率。选择策略可以保留少量均匀覆盖位置，避免搜索完全被原分布限制。

计算量也需要实测。例如，若每边有 33 个 bin、每个候选取 9 个点、每张图有 300 个 query，则单特征层上共有 \(4\times33\times9\times300=356{,}400\) 个采样点。这个计数不等于实际运行时间，但说明完整版本不能事先宣称“几乎没有额外成本”。

### 5.7 初版训练与接入原则

1. 在末层原 logits 产生之后、原期望解码之前进行修正，训练和推理走同一条路径。
2. 使用修正后的 logits 和框计算原有 FGL、L1、GIoU 等损失，不先增加新的非对称损失。
3. 如果末层分布参与自蒸馏、质量估计或其他辅助监督，对应张量应来自同一版本的预测，避免新框配旧分布。
4. 新增修正网络的最后一层可以零初始化，使初始输出与基线一致。
5. 初版沿用现有特征层。是否引入更高分辨率特征作为单独变量，不与候选取证机制混为一谈。

本方案首次验证的是框坐标是否改善；不以分布更尖、熵更低或可视化更好看作为成功标准。

## 6. Related Works：已有工作与方案的实质关系

本节重点比较会直接限制创新表述的研究。文献覆盖用于确定方案边界，不代表已经证明全领域不存在相同机制。

### 6.1 GFL：灵活的分布式框回归已经存在

[Generalized Focal Loss: Learning Qualified and Distributed Bounding Boxes for Dense Object Detection，NeurIPS 2020](https://proceedings.neurips.cc/paper/2020/hash/f0bda020d2470f2e74990a07a607ebd9-Abstract.html)使用离散向量表示边界位置分布，并通过 Distribution Focal Loss 等设计进行学习。

**与本方案的重合：** 都允许同一条边有多个候选，并用分布表达定位，而不是只预测一个偏移量。

**可能的区别：** 本方案关心各候选如何从对应位置获得新的空间证据，而不是提出另一种分布表达。仅把输出从高斯改为离散分布、允许非对称形状，不能算本方案的新贡献。

### 6.2 D-FINE：最直接的方法基础

[D-FINE: Redefine Regression Task in DETRs as Fine-grained Distribution Refinement，ICLR 2025](https://arxiv.org/abs/2410.13842)已经研究了四边离散分布、非均匀候选偏移、残差细化和层间定位自蒸馏。

**与本方案的重合：** 分布状态、逐步细化和残差 logits 更新均沿用这一基础。不能把这些设计重新命名后作为独立贡献。

**可能的区别：** 在现有实现中，分布头由解码特征产生各 bin 的得分修正；本方案增加的是“bin 对应的实际边界位置 → 局部取证 → 该 bin 的得分修正”这条显式路径。

这不等于 D-FINE 没有空间信息。合理表述应是比较两种利用空间信息的方式，而不是先断言 D-FINE 存在已被证实的缺陷。最基本对照是同一 D-FINE 配置中加入和移除该路径。

### 6.3 LocNet：边界概率、内外信息和迭代定位都已有先例

[LocNet: Improving Localization Accuracy for Object Detection，CVPR 2016](https://arxiv.org/pdf/1511.07763)在扩展搜索区域内，对每行、每列预测位置相关概率。它可以预测位置是否属于框内部，也可以预测四条边的位置概率，通过组合似然确定框，并在检测流程中迭代使用。论文还讨论了多峰边界概率。

**与本方案的重合很明显：** 空间对应的边界概率、多候选、内部／外部信息、高 IoU 定位及迭代使用，都不能笼统写成新思想。

**需要区分的细节：** LocNet 的 In-Out 表示一行或一列属于目标框内部的概率，并非在每个候选边界的法向两侧提取局部条带特征。它从搜索区域特征生成位置概率并解码；本方案则在 D-FINE 原有分布状态上，对候选位置重新取证，再把残差写回对应 bin。

因此，差异应限定在“候选条件下的局部取证和原分布更新结构”。如果最后只是从一个扩大 RoI 生成新的四边概率，本方案与 LocNet 的区别就会明显减弱。

### 6.4 SABL：逐边定位和候选空间对应也不是新的

[Side-Aware Boundary Localization for More Precise Object Detection，ECCV 2020](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123490392.pdf)将 RoI 特征沿两个方向聚合成一维侧向特征，再通过空间 bucket 分类和桶内偏移回归定位四条边。论文也测试了迭代分桶。

**重合点：** 逐边定位、具有空间意义的离散候选、侧向特征及细粒度修正，都已有直接先例。

**可能的区别：** SABL 主要从 RoI 的侧向特征完成 bucket 预测；本方案从已有边界分布出发，在不同候选位置各自的内外条带上取证，并修正原分布。不是只选择一个桶后输出该桶内的一个偏移。

**必须回答的问题：** 保留候选对应关系并更新完整分布，是否优于已有侧向特征加分桶定位？仅展示优于普通回归头还不足以解释这一区别。

### 6.5 BorderDet：最重要的边界采样对照

[BorderDet: Border Feature for Dense Object Detection，ECCV 2020](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123460528.pdf)先预测粗框，再通过 BorderAlign 沿四条边双线性采样并聚合特征，结合原有特征修正分类和框回归。

**重合点：** 根据预测位置提取边界特征、预测后再次取证、再细化框，都已存在。

**可能的区别：** BorderDet 围绕一个粗框提取边界特征；本方案围绕同一条边的多个候选分别提取证据，直接改变各候选的竞争关系。条带的内外两侧也是一个需要独立验证的扩展。

最重要的公平对照是：使用相同特征层、接近的参数量和采样预算，比较“单框边界取证后细化”与“多候选取证后逐 bin 更新”。如果只增加了更多采样点，不能把收益全部归于新机制。

### 6.6 GFLv2：提高框的评分与提高框的坐标需要区分

[Generalized Focal Loss V2: Learning Reliable Localization Quality Estimation for Dense Object Detection，CVPR 2021](https://arxiv.org/abs/2011.12885)利用四边分布的 Top-k 概率值及其均值，通过轻量网络预测定位质量，并与分类分数结合。

**重合点：** 利用分布信息改善检测性能，不是本方案的新概念。

**可能的区别：** GFLv2 的质量分支主要利用概率统计生成质量标量；本方案保留候选的空间坐标，重新提取对应图像特征，输出各 bin 的定位修正。

这一区别也决定了实验要求：除了正常 AP，还需要固定细化前分数、仅替换新旧框的分析，避免把置信度排序改善全部解释为坐标更准确。

### 6.7 Grid R-CNN：概率空间定位和多点几何证据已有基础

[Grid R-CNN，CVPR 2019](https://openaccess.thecvf.com/content_CVPR_2019/papers/Lu_Grid_R-CNN_CVPR_2019_paper.pdf)为框上的规则网格点预测二维热图，例如角点、边中点和中心，再融合这些点确定框；点特征之间也进行信息交互。

**重合点：** 用明确的空间概率位置以及多个几何证据提高精度，已有先例。

**关键区别：** Grid R-CNN 预测多个不同几何点各自的位置；本方案的多个 bin 表示同一条边相互竞争的位置假设。前者通过点热图和特征交互定位，后者通过候选位置的局部取证更新已有边缘分布。

论文还讨论了扩大 RoI 引入背景或其他物体、影响小目标检测的问题。因此，不能预设取更多框外信息必然有益，条带宽度和邻近目标干扰都应通过实验判断。

### 6.8 Cascade R-CNN：高 IoU 检测和多阶段精修本身不是新问题

[Cascade R-CNN: Delving into High Quality Object Detection，CVPR 2018](https://openaccess.thecvf.com/content_cvpr_2018/papers/Cai_Cascade_R-CNN_Delving_CVPR_2018_paper.pdf)通过多级检测器和逐步提高的正样本 IoU 阈值，使输入框质量、训练样本质量和检测器阶段相匹配。前一级修正后的框进入后一级。

**重合点：** 从粗定位走向精定位、多阶段修正、重点改善高 IoU 检测，都已有成熟研究。

**可能的区别：** Cascade R-CNN 主要改变阶段训练方式和样本质量；本方案主要改变每次定位更新从哪里获取证据，以及证据如何与边界候选对应。增加几层修正本身不构成这一区别。

初版不同时改变正样本阈值和训练日程，以免无法分清收益来自取证模块还是训练策略。

### 6.9 小目标专用度量与匹配：NWD、RFLA、SAFit

[NWD，2021 预印本](https://arxiv.org/abs/2110.13389)将框映射为二维高斯，用归一化 Wasserstein 距离衡量相似性。这里的高斯主要是框的几何表示，不能直接等同于预测误差或标注噪声分布。

[RFLA，ECCV 2022](https://arxiv.org/abs/2208.08738)利用高斯感受野先验和相应距离设计标签分配，改善极小目标的正样本学习。

[Visible-Thermal Tiny Object Detection: A Benchmark Dataset and Baselines，2024 预印本](https://arxiv.org/html/2406.14482v1)提出 SAFit，按目标尺度结合 IoU 与 NWD。

**与本方案的关系：** 这些工作主要改善几何度量、监督或匹配；本方案研究的是视觉证据与定位分布更新。二者可能互补，也可能在实验中出现相似收益。

不能预设 NWD 等方法只能提高 AP50、不能改善高 IoU 定位。它们应作为相关强基线或补充对照。使用不同评测度量的论文数值，也不能直接拿来与标准 IoU AP 比较。

### 6.10 定位噪声和非对称代价：保留为相关背景

[DN-TOD：Robust Tiny Object Detection in Aerial Images amidst Label Noise，2024 预印本](https://arxiv.org/html/2401.08056v1)研究极小目标的类别和框标注噪声，通过学习趋势等机制改善监督。

[TOLF：Noise-Robust Tiny Object Localization with Flows，2026 预印本](https://arxiv.org/html/2601.00617v1)利用流模型表达复杂定位误差，包括偏斜、厚尾和多峰，并进行不确定性感知优化。因此，“极小目标 + 非高斯误差分布”本身不足以构成强创新。

[Aligning Object Detector Bounding Boxes with Human Preference，ECCV 2024 Workshop](https://arxiv.org/abs/2408.10844)已经研究鼓励较大框的非对称回归损失。人对展示框的偏好，也不等于人工训练标注存在普遍外扩偏差。

**本方案的区别：** 研究目标是常规小目标检测中的高精度定位；方法依赖候选边界的图像证据，不依赖先证明标注有偏，也不依赖估计噪声分布。上述工作可以用于讨论鲁棒性和创新边界，不作为论文主线。

### 6.11 创新边界的归纳

| 不能单独作为新贡献的表述 | 需要真正验证的具体设计 |
| --- | --- |
| 用概率分布预测框 | 对原有候选分布进行位置对应的局部取证更新 |
| 四条边分别定位 | 同一条边的多个竞争候选分别获得证据 |
| 利用边界或内外信息 | 候选边界法向两侧的局部条带是否有独立价值 |
| 预测后再细化 | 保留候选对应关系是否优于单框细化和汇总特征 |
| 面向高 IoU 检测 | 小目标上的高 IoU 收益是否真实、稳定且代价合理 |

目前可以提出的是一种有具体机制和验证路径的研究设计，不能预先使用“首次”“填补空白”或“已解决 D-FINE 的关键缺陷”等结论性表述。

## 7. 实验设计：证明改善的是定位，并解释为什么

### 7.1 用已有预测完成最小诊断

第一步不必训练新模型。优先从已有预测中查看：

1. 在统一的一对一匹配规则下，预测落在 IoU 0.50–0.75、0.75–0.90 等区间的情况，并按目标尺寸分组。
2. 中心误差、宽高误差和四边误差，判断更需要修正平移还是目标范围。
3. 如果基线为 D-FINE，查看各解码层在同一组目标上的 IoU 变化，判断末层是否仍有可用的精修空间。

可以参考 [TIDE，ECCV 2020](https://arxiv.org/abs/2008.08115)区分定位、重复预测、漏检等误差，但不需要把诊断扩大为全仓库或全系统审查。

如果几何误差不是主要提升空间，后续方案应调整；如果高分预测中有大量框停留在 0.50–0.75，则更支持开展定位精修实验。

### 7.2 最重要的局部对照

优先在一个 D-FINE 规模、一个数据集和固定训练配置下比较。以下是研究对照，不要求一开始全部并行训练。

| 编号 | 设置 | 要回答的问题 |
| --- | --- | --- |
| A | 原始 D-FINE | 基础性能 |
| B | 相近参数量的普通特征修正分支 | 收益是否只是增加参数和网络容量 |
| C | 围绕单个预测框的 BorderAlign 式边界取证 | 多候选是否优于单框边界细化 |
| D | 多候选取证，但先汇总特征再预测整组修正 | 相同位置取证时，保留候选对应关系是否必要 |
| E | 多候选、逐候选对应的边界线取证 | 候选对应机制是否有效 |
| F | E + 内侧／外侧条带 | 两侧证据是否带来额外定位收益 |

比较 C–F 时，尽可能匹配所用特征层、采样预算和参数规模，至少完整报告差异。预算严格匹配会改变采样分布时，需要说明具体分配方式。

更高分辨率特征、增加 bin 数量和稀疏候选选择作为后续独立变量。尤其要比较“基线 + 高分辨率特征”与“高分辨率特征 + 本模块”，避免把分辨率收益误归于候选机制。

如果要进一步诊断对应关系，可以打乱候选与证据的对应后重新训练。随机错配更适合破坏这种关系；固定、可学习的置换可能被网络重新学回。仅在测试时突然打乱产生的性能下降还包含分布外扰动，不能单独作为机制成立的证据。

### 7.3 如何证明框坐标确实改善

在同一模型、同一批 query 输出中，保存细化前后的框，并固定细化前的分数，分别计算标准 AP。这样可以部分隔离分数重排的贡献。

再做目标级诊断：按 GT 定义共同评估集合，分别记录两种输出都匹配到、仅一方匹配到和均未匹配到的目标。对于共同匹配目标，比较像素边界误差与 IoU；对于其他目标，保留漏检或新增检出的记录。

“只看基线已经在 IoU 0.50 下命中的目标，有多少提升到 0.75”是有用的条件分析，但不能替代全测试集指标。它也不能遗漏原本通过 0.75、细化后反而退化的目标。

建议同时报告上升和下降的数量，以及按尺寸分组的变化，而不是只展示成功案例。

### 7.4 指标与公平性

| 指标 | 用途 |
| --- | --- |
| AP75 | 核心高精度定位指标 |
| AP@[.5:.95] | 保证总体检测精度改善 |
| AP50、召回 | 检查是否牺牲了已有检测能力 |
| AP85／AP90 | 辅助观察更严格重叠要求下的变化 |
| 小目标尺寸分组 AP | 验证收益是否集中在研究对象上 |
| 中心、宽高、边界像素误差 | 解释框究竟在哪些方面变得更准确 |
| 延迟、显存、参数量 | 判断新增计算是否值得 |

AP50 与 AP75 的差值只能用于描述，不能作为独立优化目标，因为降低 AP50 也会让差值缩小。

尺寸分组应说明使用原图还是网络输入坐标。最好保留数据集官方分组，同时记录缩放后目标的实际像素尺寸，以便解释特征取证难度。

首轮使用 UAVSwarm 和既定基线配置。核心机制成立后，再补充另一种场景的小目标数据，例如 [AI-TOD-v2](https://chasel-tsui.github.io/AI-TOD-v2/)，验证适用范围。最终主要对照应使用多个随机种子报告波动；预训练、输入尺寸、训练轮数、后处理及评测协议保持一致。

历史论文报告的 AP 不能直接拼成公平对比表。不同检测器架构难以统一时，应区分“公开参考结果”与“同一基线内的受控对照”。

### 7.5 哪些结果支持或否定方案

| 观察结果 | 更合理的解释 |
| --- | --- |
| F 稳定优于 A、B、C、D，固定分数后高 IoU 指标仍改善 | 支持候选对应取证和条带机制的价值 |
| C 与 F 接近 | 普通边界特征可能已足够，多候选机制的必要性不足 |
| D 与 F 接近 | 收益可能来自新增局部特征，不一定来自逐候选对应 |
| E 与 F 接近 | 两侧条带未提供明确增益，可以简化模块 |
| 只有加入更高分辨率特征才改善 | 需要进一步拆分取证机制与分辨率的贡献 |
| 正常 AP 改善，但固定分数和几何误差不改善 | 收益可能主要来自评分或排序变化 |
| 仅 AP50 改善，高 IoU 指标无改善 | 尚未支持本文的高精度定位主张 |

## 8. 当前方案的限制与可选扩展

首版将其他边暂时固定，只更新某条边的候选权重，是一种简化。四条边在几何上存在相关性；若诊断发现主要问题是整体平移或共同缩放，可再研究中心、尺度或边之间的联合约束。

对极小、模糊到缺少可辨细节的目标，局部取证可能无法提供足够信息。高分辨率输入、浅层特征或其他观测方式可能更重要，不能要求概率更新恢复不存在的信息。

条带过宽可能引入邻近目标，过窄可能得不到足够差异；这是需要验证的超参数，不应事先设定“越宽越好”。

标注噪声仍会影响训练和高阈值评测。必要时可增加小规模扰动鲁棒性分析，但不把复标数据、误差通道估计或噪声分布学习设为本方法成立的前提。

非对称输出损失、联合四边分布、多层取证和概率指导稀疏采样均可作为后续扩展。首版不同时引入，避免无法判断哪个设计真正有效。

## 9. 与当前工作区的对应及建议推进顺序

当前工作区中，与该方案直接相关的位置是：

| 文件 | 相关内容 | 后续实现用途 |
| --- | --- | --- |
| [dfine_decoder.py](../../src/zoo/dfine/dfine_decoder.py) | 分布预测、FDR、Integral、解码层输出 | 在末层 logits 到期望解码之间接入取证修正 |
| [dfine_utils.py](../../src/zoo/dfine/dfine_utils.py) | 非均匀支持值、框与边偏移之间的变换 | 保证候选采样坐标与原解码含义一致 |
| [dfine_criterion.py](../../src/zoo/dfine/dfine_criterion.py) | FGL、几何损失及分布蒸馏等 | 保证更新后的分布、框和辅助监督相互一致 |

上述是实现定位，不代表已经修改这些文件。

建议按以下顺序推进：

1. **确认提升空间：** 用现有预测完成定位误差和尺寸分组诊断。
2. **实现最小原型：** 只加末层、完整候选、现有特征层，保持原损失和解码。
3. **验证机制：** 优先完成单框取证、候选汇总、逐候选取证和内外条带的关键对照。
4. **验证适用性与成本：** 核心收益稳定后，再进行跨数据集、随机种子和计算效率实验。

## 10. 可以采用的论文立意表述

在得到实验结果前，可以这样描述研究目标：

> 小目标检测对微小的框坐标误差高度敏感，使得较好的粗定位性能并不必然转化为严格 IoU 阈值下的高检测精度。本研究沿用分布式边界定位的基础，探索候选边界与局部图像证据之间的显式对应关系：在多个候选边界及其两侧获取特征，并将这些证据用于修正对应的定位分布。研究目标是提高小目标边界细化的准确性，而不是预设标注噪声的形式。

只有当相应实验成立后，才能进一步写成“方法提高了 AP75”“候选对应关系优于汇总特征”或“内外条带具有独立贡献”。论文中的数值结果、失败案例和创新结论都应由实验补充，不能由当前方案推测代替。
