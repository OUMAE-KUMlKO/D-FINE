## 当前 GT 算法究竟优化什么

先保留原生 Top300 的顺序，再从其余候选补齐 Top1200。候选 i 对 GT g 的质量为：

```text
q(i,g) = IoU(候选粗框 i, GT框 g) × 1[候选预测类别 = GT类别]
u(i,g) = 1[q(i,g) >= 0.5] + 0.01 / max(1, GT数量) × q(i,g)
F(S)   = sum_g max_{i in S} u(i,g)
Δ(a,r | S) = F(S 去掉 r 加入 a) - F(S)
```

每一步选择净增益最大的交换，最多 40 步，增益不为正则停止。
只允许移除尚在集合中的原生 query、加入从未选入的池内候选，避免循环。
这个目标优先增加可覆盖 GT，再用 IoU 总质量打破近似平局。
它显式计算移除损失，因此“把一个漏检目标补进来”和“同时把另一个唯一代表删掉”不能混为净收益。
它没有直接优化 COCO AP，也不保证一对一覆盖或全局最优集合。

## 旧设计的不足及证据

### 1. 首版代表性标签与有效覆盖之间存在偏差

`association()` 先按粗框几何关系关联 GT，再使用 Hungarian 匹配选出代表候选。
关联本身不检查类别，并允许较宽松的 IoU/中心/面积比例条件。
代表性 BCE 鼓励预测某个匹配解里的候选身份；同一实例的其他可用候选会作为非代表处理。
这个标签未必对应“增加一个类别正确、粗框可用的新实例”，还可能随近似候选的匹配变化而改变。

首版 80 轮实际表现：

- AP=28.5892，原 G5=29.2135，下降 0.6243 AP。
- 每图平均替换 40.7518 个，但类别正确且 IoU≥0.5 的覆盖仅从 66.1008% 到 66.2246%。
- 代表标签覆盖从 76.6635% 到 78.6991%，明显大于实际有效覆盖的改善。
- 小目标有效覆盖从 56.7902% 到 56.7789%，没有改善。

证据：`output/g5_boundary_selection_scratch80_20261107/analysis_20261108/{training_summary,selection_summary}.json`。
因此，首版的问题不能只解释为训练时间不足；它本身已经完整训练过 80 轮。

### 2. 单个候选的好坏，不能代替选中集合的价值

原实现最终统一计算 `class_logit + 0.5 × representative_logit`，一次 Top300。
质量排序版改为类别正确 IoU 监督，并加入同一 GT 内的优劣排序，方向比原代表性标签更贴近检测质量。
但它仍缺少当前已选集合 S：加入第一个目标 A 的候选与加入第十个目标 A 的候选，评分机制没有显式不同。
同一 GT 内排序正确，也不能保证不同 GT 之间的排序能把新实例带入 Top300。

冻结 G5 的 6 轮质量排序实验中：

- 成对排序准确率从 83.7358% 到 85.4430%。
- 每图平均替换 34.7336 个，覆盖率从 66.6503% 到 66.8567%，只增加 0.2064 个百分点。
- 最佳训练后 AP=29.1747，没有超过原 G5。

证据：`output/g5_selection_quality_rank_20261108/summary.json`。
本次 GT 全量实验则能让筛选后覆盖率接近当前池覆盖率，提示“净覆盖收益”是更直接的目标。

### 3. 关系分支的证据被压缩，且首版监督不完整

原关系只考察局部邻居，并把关系概率压缩为三个统计量后交给单候选评分头。
它没有在最终选择时明确执行“同一实例候选之间竞争、不同实例尽量保留”。
首版只有约 22.78% 邻接边受到关系监督；未监督边平均预测概率约 0.59。
这些边也可能影响统计量。质量排序版已补充背景负边和前景门控，修复了一部分缺口，但没有改变静态 TopK 机制。

此外，固定 32 像素网格、局部 K=8、每格截断候选并不保证覆盖真正相关的邻居；
单尺度、固定像素边界采样对极小目标是否足够稳定，也需要实测。
这些是实现层面的潜在限制，目前没有独立消融证据，不能把它们当作已经确定的主要原因。

### 4. 分数尺度和硬索引使监督目标格外重要

首版代表残差的标准差约 1.5739，原类别 logit 约 0.9678；残差已足以显著改变排序。
增加残差强度或更换更多 query 并不意味着补入更多实例。
通过 TopK 整数索引选择候选时，最终检测损失不能直接对索引求导来训练排序分数；
筛选头主要依赖显式辅助监督。因此辅助目标偏离实际选择收益时，decoder 的 AP 损失不会自动修正这一偏差。

### 5. 先前部分验证协议低估了联合训练空间

6 轮质量排序是冻结检测器的监督探针，12 轮 GT 实验也冻结了候选生成器和其他大部分模块。
这些实验可以判断固定候选上的监督是否有用，不能据此限定完整联合训练的潜力。
GT 全量训练允许候选池、特征、decoder 和 G5 修正头共同适应，候选池覆盖率已经超过原来的 70.75%。
但其验证使用 GT，且与 12 轮的可训练范围、增强、学习率和时长不同，不能单独证明某种初始化必然更好。

## 建议：学习相对于已选集合的净覆盖收益

我建议下一版采用“质量估计＋实例区分＋集合条件交换”，先保留 Top1200、300 个 query 和最多 40 次交换的边界。
这样可以直接针对已验证有效的 GT 决策机制进行学习，而不同时扩大 query 数量、修改 query 内容或引入新修正头。
以下是待验证设计，不承诺能复现 GT 验证 AP。

### 输入与输出

- 候选特征使用 encoder memory、预测类别/置信度、粗框几何，必要时加入现有局部视觉证据。
- 质量头估计类别正确且定位可用的概率，连续 IoU 可作辅助；初版目标与当前 GT 覆盖口径对齐。
- 关系头预测两个候选是否对应同一实例，不能直接用框 IoU 代替实例身份，尤其要处理相邻同类目标。
- 选择头读取当前已选集合或其关系汇总，预测“加入 a 并移除 r”后的净收益，包括新增覆盖与丢失覆盖。
- 推理从原生 Top300 开始，根据预测收益交换；到达预算或没有正收益则停止，GT 不参与前向决策。

例如，当前集合中 A 有 8 个候选、B 没有候选；A 的第 9 个候选即使质量更高，也应与 B 的首个可用候选区别对待。
若候选 r 是 C 唯一有效代表，则替换 r 的代价必须计入，不能只判断候选 a 是否覆盖 B。
“仅按低置信度删 query”或“只预测候选属于前景”都不满足这个要求。

### 监督方式

使用训练集 GT 在当前学生候选和当前已选集合上计算交换净收益，教师目标不反传。
对正收益交换、会丢失唯一实例的交换、收益近零的交换分别提供排序或回归监督，并包含“不交换”动作。
同一实例的近似等价候选允许软目标或并列，不强迫学生复现某个唯一 Hungarian/贪心索引。
对难以可靠归属的重叠候选，避免简单把“几何位置近”硬标成同一实例。

训练状态应包含学生自己选出的集合，不能只在 GT 教师产生的理想集合上训练，否则推理时的错误状态缺少监督。
GT 教师根据当前候选在线计算；原 G5 的固定候选缓存不能用于 80 轮学生联合训练。
保留显式选择监督，使离散索引无法接收的检测梯度由与决策一致的辅助目标补足。
检测损失继续训练实际被选中的候选分支、主干、decoder 与 G5 修正头。

### 与检测器共同训练

学生的训练与验证选择路径保持一致：均由预测完成选择，GT 仅用于训练损失和离线诊断。
从主干预训练开始完成 80 轮，沿用本次六卡和原 G5 协议。
若训练初期质量预测不可靠，可短暂沿用原生 Top300，同时训练选择损失，再逐步打开预测交换；
具体启用时机需要结合早期指标决定，不能先指定未经验证的最优轮数。
不直接长期把 GT 选择喂给 decoder 再在验证时突然切为学生选择，这会引入选择分布差异。

### 判断是否有效

主要指标仍是无 GT 验证 AP。同步观察类别正确 IoU≥0.5/0.75 覆盖、一对一覆盖、小目标和密集图子集、
补入与丢失实例数量、每图交换数和推理耗时。单独的辅助 loss 下降、排序准确率或换入数量都不够。
先检查同一候选池内学生是否明显缩小“原生 Top300 与 GT 选择”的覆盖差距，再判断联合训练最终 AP。
如果覆盖未改善，优先检查目标与选择机制；如果覆盖改善而 AP 不改善，再检查定位质量和 decoder 的利用情况。

## 与相关工作的关系

[DDQ 原论文](https://arxiv.org/abs/2303.12776) 强调从密集候选中保留具有区分性的 query，再进行一对一匹配。
这支持同时关注候选覆盖和冗余，而不是只提高单个候选分数；本文的集合条件交换是针对本地证据提出的设计，不能称作 DDQ 已验证的结论。

[DQ-DETR 原论文](https://arxiv.org/abs/2404.03507) 同时包含计数、计数引导特征增强和动态 query 选择，
不能把其完整增益都归因于固定 300 个 query 的重排序。
当前 GT 实验在固定 300 个 query 下已有收益，因此下一版优先学习有效选择，暂不同时引入动态数量模块。
