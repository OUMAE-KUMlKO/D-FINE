# VisDrone 最佳 G0 / G5 错误构成诊断

## 范围与执行方案

用户已批准比较错误构成。使用续训实验中各自最佳 epoch 96 EMA：原版 G0 与六层自适应带宽 G5。复用已完成视觉消融的 G5 normal 预测，仅补 G0 的 548 张验证图推理。保持 640×640、FP32、原后处理 top300、COCO 每图每类 maxDets100；不训练、不改模型、不提交。

1. 缓存 G0 原始框与 logits，核对图像、GT、尺寸与 G5 缓存完全相同，并核对 AP 与保存结果。
2. 用官方 COCO 匹配拆分 TP、忽略预测和 FP。FP 按优先级分为：重复检测（已匹配的同类有效 GT 的 IoU 达标）、分类错误（异类有效 GT 的 IoU 达标）、定位错误（同类 IoU≥0.1 但未达标）、分类及定位错误（异类 IoU≥0.1 但未达标）、背景误检。忽略/crowd GT 不作为错误类别归属依据。
3. 在 IoU=0.5/0.75、置信度≥0/0.1/0.3/0.5 下统计 TP、FP 和漏检（有效 GT−达到分数门槛的 TP），辅以各类 AP、官方尺寸 AP。固定置信度计数受分数校准影响，不直接当作 AP 差距。
4. 完整分数序列下，固定匹配、GT 分母和截断集合，逐 IoU 删除一种 FP 后重算 101 点插值 AP。该数值仅表示这一组误检对排序精度的影响，不补框、不修复漏检，不称为完整 TIDE 或因果归因，各项不能相加。原始 PR 需逐类逐 IoU 与官方评估一致。
5. 用每类 AP 差除以有效类别数，精确分解总 AP 差；结合错误构成，限定下一步最值得验证的假设。

必要验证：小型有已知正确答案的检测/忽略样例、PR 与官方一致、缓存对应关系与全验证集 AP。新文件保持未提交。

## 结果

已完成。结论限定于本次两个最佳 checkpoint：**总差距主要对应现有输出的可达召回下降，类别间有明显差异；背景误检增多并不能解释大部分 AP 差距，也没有出现严格 IoU 下全面退步的模式。** 这仍不是对内部致因的证明。

### 评估编号修正与复现

原验证集有一个 GT 的 annotation ID 为 0（image 0、car）。COCO 的 `dtMatches=0` 同时表示未匹配；最小样例证明，当前 pycocotools 和 faster_coco_eval 都会把 ID=0 的完美检测当作 FP。单纯核对两个评估器并不能发现这一共同问题。

本次仅在**内存副本**中给所有 annotation ID 加 1，框、类别、图像 ID、面积及原标注文件均未改变。后文错误构成、类别贡献及 AP 分解统一采用修正编号后的评估；历史结果不覆盖。

| 口径 | G0 AP | G5 AP | G5−G0 |
| --- | ---: | ---: | ---: |
| 原 ID，缓存复评 | 28.622623 | 28.418829 | −0.203794 |
| 正 ID，本次错误分析 | 28.623509 | 28.419801 | −0.203709 |

编号修正让两者分别增加 0.000887 / 0.000972 AP 百分点，对模型差距仅影响 +0.000085 个百分点，不改变判断。原 ID 复评与各自缓存生成时的 AP 完全一致；G0 缓存生成 AP 与训练日志相差 −0.000097 个百分点。

- G0 推理：Slurm **16810**，`COMPLETED 0:0`，gpu6，28 秒；548 图、38,759 个有效 GT，与 G5 逐图尺寸和 GT 一致。
- 原 ID 分析：**16811**，`COMPLETED 0:0`，gpu14 CPU，2 分18秒。
- 正 ID 分析：**16812**，`COMPLETED 0:0`，gpu14 CPU，2 分24秒。复用预测缓存，没有重新跑模型。
- 正 ID 重算 PR 与 pycocotools 逐元素偏差为 0，与 faster_coco_eval 最大偏差为 `2.22e-16`。

### 1. 总体差距更偏向可达召回下降

固定现有输出、匹配和 maxDets，按每个 IoU 理想地删除全部 FP、保留 TP，可得到一个 AP 上限。这里不补回漏检，也不重新匹配。这是诊断上限，不能用一个可部署的筛选规则实现。

具体从每类、每个 IoU 的未舍入 AR100 计算：101 个召回采样点中，不超过 AR100 的比例为该组上限；AR100=0 时上限为0，无 GT 的类别不参加平均。先分组计算，再对类别及 IoU 平均。

| 指标，百分数/百分点 | G0 | G5 | G5−G0 |
| --- | ---: | ---: | ---: |
| 固定 TP 的可达 AP 上限 | 43.207921 | 42.930693 | −0.277228 |
| FP 带来的精度损失，上限减实际 AP | 14.584411 | 14.510892 | −0.073519 |
| 实际 AP | 28.623509 | 28.419801 | −0.203709 |

因此 `−0.203709 = −0.277228 − (−0.073519)`。G5 的可达上限下降，误检带来的精度损失反而略小，抵消了部分下降。**仅改善误检排序不能补回缺少的达标正确框。** 但可达上限同时受框的位置、类别预测、top300/每类maxDets截断影响，不能把这一项直接命名为“定位模块造成的损失”。

### 4. 错误计数及其对 AP 的影响

以下为 IoU=0.50、score≥0.1；漏检是38,759减达分TP，未使用几何 Hungarian 未匹配数。

| 类型 | G0 | G5 | G5−G0 |
| --- | ---: | ---: | ---: |
| TP | 29,836 | 29,746 | −90 |
| 重复检测 FP | 11,461 | 10,304 | −1,157 |
| 分类 FP | 30,743 | 30,147 | −596 |
| 定位 FP | 13,818 | 13,493 | −325 |
| 分类及定位 FP | 17,499 | 17,399 | −100 |
| 背景 FP | 28,577 | 30,581 | +2,004 |
| FP 合计 | 102,098 | 101,924 | −174 |
| 漏检 | 8,923 | 9,013 | +90 |

同一分数门槛下，IoU=0.75 的漏检为20,182→20,350（+168）。取消额外置信度门槛、保留既定 top300/maxDets 输出后，IoU=0.50/0.75 的漏检仍分别增加85/167。另一方面，score≥0.3、IoU=0.50时，G5的TP增加25而FP增加1,376；固定阈值数量受分数分布影响，不能单独用于归因 AP。

下表逐个删除一种 FP，保留原有匹配、排序和召回分母，各行独立计算，不能相加：

| 理想删除的 FP 类型 | G0 AP 恢复 | G5 AP 恢复 | 删除后 G5−G0 |
| --- | ---: | ---: | ---: |
| 重复检测 | +0.155432 | +0.122207 | −0.236934 |
| 分类 | +3.845312 | +3.789334 | −0.259687 |
| 定位 | +2.275327 | +2.237461 | −0.241575 |

| 背景 | +0.839184 | +0.845148 | −0.197745 |

背景 FP 虽多了2,004个，理想删除背景错误也只让模型差距缩小约0.00596个百分点。分类 FP 是两模型共同的较大损失，但这不能证明它是 G5 相对退步的主因。去错收益较小也不能独立证明分类或定位能力更强，因为收益受 TP 集合、可达召回和排序共同影响。

### 5. 后续建议与边界

优先追踪 **bicycle / truck 中 G0 正确检出、G5 漏检的同一 GT**：检查 G5 是否已有位置达标的框却类别不对或落在候选截断之外，还是位置本身未达标。对 awning-tricycle / van 则优先看正确框与误检的类别分数及排序，必要时再检查分布变化到 LQE 分数的路径。

本次尚不能断定是 LQE、分类损失或联合训练造成差距，也不据此直接增加背景抑制、门控、更高分辨率特征或训练时长。先前的视觉置零、随机噪声和修正强度消融结论不变：视觉修正确实有用；当前问题是它未能让整体检测结果超过 G0。该结论仍限于本次 VisDrone checkpoint 对，不构成两数据集差异的完整因果解释。
