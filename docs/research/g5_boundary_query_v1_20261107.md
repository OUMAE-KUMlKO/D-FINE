`visdrone_g5_ddf_off_seed0_ap28.5186/training/best_stg2.pth` 的 EMA 权重。
原六层 33 候选/边、5×7 边界带、64 维 query 门控、logit 残差全部保留；
DDF=0、FGL=0.15，最终 decoder query=300。

## 首版结构

1. 原 encoder 最大类别 logit 取 Top1200，完整保留原 Top300。
2. 在 stride-8 特征上投影到 C32，每个候选四条边各采样 3×3 点：
   切向覆盖边长，法向偏移为 −4/0/+4 输入像素。
   越界采样屏蔽，沿切向按有效点归一化；保留四侧及法向位置后编码为 z。
3. 融合候选语义、类别、框几何及 z。用 32 像素网格的相邻九格建立有界局部邻域，
   每格最多检查 K+1 个候选，再取最近 K=8 个；不构造 M×M 关系矩阵。
   关系头预测同实例概率，并汇总邻居关系及更强竞争者的信息。
4. 排序分数为 `原最大类别 logit + 0.5 × 代表性 logit`。
   存在性头仅作辅助监督，不直接参加排序。0.5 是保守初值，不声称为最优系数。
5. 选中 300 个后，复用上述状态预测内容及参考框残差：
   `q = 原候选内容.detach() + Δq`；
   `reference_unact = 原粗框_unact.detach() + 0.5*tanh(Δb_raw)`。
   新残差保留梯度，参考框修正限幅，原 FDR 分布初始化及六层细化不变。
   构建头只计算选中的 300 个，不再为全部 1200 个计算构建输出。
6. 新增输出头末层零初始化，因此初始排序、内容、参考框退化回原 G5。
   新模块注册为正常子模块，兼容 DDP、EMA 和 checkpoint；不使用运行时 monkey patch。

## 候选关联与监督

沿用预实验验证的 hybrid 关联：IoU≥0.3，或 IoU≥0.05 且中心位于 GT 框内、
候选/GT 面积比在 [0.25,4]。多个有效 GT 的最高与次高 IoU 差 <0.05 时标记歧义。

- 存在性：任意有效关联即为正，含歧义；背景为负。
- 代表性：有效边上做一对一 Hungarian 匹配，优先最大有效匹配数，
  再最小化 `1−IoU + mean(abs(cxcywh差)/GT_whwh)`；允许 GT 无候选。
  歧义候选可以成为匹配正例，未匹配的歧义候选不作为代表性负例。
- 关系：仅两端都有明确 GT 归属且邻接有效时监督，同 GT 为正、不同 GT 为负。
- 按 GT 均衡、正负均衡的 BCE，权重依次为 1、1、0.25。
  在完整 Top1200 上独立计算，使未选中的候选也能学习。
  匹配及离散索引无梯度；模型推理不访问 GT。
- 内容与参考框残差通过原检测损失学习。暂不新增构建代理损失。

`query_aux_outputs` 与原 encoder auxiliary outputs 分开：原辅助输出始终只有
选中 300 个的原始类别和粗框，与 decoder/DN 索引一致；M 个候选不进入原联合匹配索引。

## 训练协议

两组均从同一归档 EMA 独立开始，重置 optimizer/scaler/EMA 计数：

| 项目 | 设置 |
| --- | --- |
| 组别与顺序 | boundary_query → g5_control，串行 |
| 每组轮数 / seed | 24 / 0 |
| GPU / batch | 单节点 8 GPU，总 batch32，每卡4 |
| 优化器 | AdamW，betas=(0.9,0.999)，weight decay=1.25e-4；norm 不衰减 |
| 学习率 | 原可训练 backbone 1e-5；encoder/decoder/G5 refiner 2.5e-5；新前端1e-3，固定 |
| 原冻结策略 | 保留归档 HGNetv2 的 stem/frozen norm 设置，其余原可训练参数继续训练 |
| 精度 / 梯度 | AMP，损失在 autocast 关闭区计算，clip norm=0.1 |
| EMA | decay=0.999，无 warmup，仅成功 optimizer step 后更新 |
| 数据 | 原 train6471 / val548；沿用原增强，前22轮多尺度及强增强，最后2轮关闭相应增强 |
| 验证与保存 | 初始及每轮完整 val；记录 AP/AP50/AP75/APs，保存 best/last |

短周期继续训练不调用原 solver 的阶段回滚/旧 best 重载，保持两组协议一致。
新方案相对于继续训练对照的 AP、AP75、APs 是本轮主要判断依据；不能仅与历史 AP28.5186 比较。
本轮两组可以检验完整模块的收益，边界证据相对语义前端的独立贡献仍需后续消融。
