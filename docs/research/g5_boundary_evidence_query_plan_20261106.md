# 基于 G5 的边界证据引导实例选择与 Query 构建

日期：2026-11-06。状态：研究路线已认可；本文记录方案，尚未实施或验证。

## 1. 背景与目的

原始 Top-K 按分类分数选择 encoder 候选，不能保证有限 query 名额覆盖不同实例，也不直接保证初始内容和粗框适合后续精修。现有 G5 在六层 decoder 中读取候选边的 strip 证据，通过 query 通道门控修正边界分布，主要改善已有目标假设的定位。

已有128张 VisDrone 图像诊断显示：在“最终漏检且初始 Top300 无 IoU≥0.3 覆盖”的子集中，输入尺度8–16像素的288个目标有228个属于候选漏选；≤8像素的634个目标有466个在完整候选池中也无达标粗框。尺寸为640输入下的平方根面积。该结果支持同时研究**候选选择与初始化质量**，不等于证明所有漏检都由这两者造成，详见[统计数据](../../output/tiny_query_topk_attribution_20261023/visdrone/attribution_summary.json)。

本方案旨在：**利用同一份边界证据，选择更有实例代表性的候选，构建更适合 G5 精修的 query，并在固定300个 decoder query 下提高检测质量。** 本轮不继续融合 Dome-DETR，也不引入密度图。

## 2. 整体结构

> 较宽的 encoder 候选池 → 轻量边界证据 → 学习实例代表性评分 → 选300个 → 构建内容与参考框 → G5逐层精修。

1. **候选池。** 保留包含原 Top300 之外位置的受控候选池，规模记为 M，且 M>300。预筛应足够宽松，避免弱目标在边界证据介入前被排除；M 不等于送入 decoder 的 query 数。
2. **边界描述。** 从每个候选的粗框附近轻量读取四边证据，结合语义特征与相对位置，得到描述 z_i。不照搬 G5 的33候选逐位置处理及多层精修；采样方式和点数不预先固定，以有效证据和额外计算预算共同约束。不要求四条边都清晰，也不依赖同一目标产生多个强响应。
3. **学习筛选。** 利用候选自身信息及局部邻域关系，预测目标存在分数与实例代表性分数，联合排序后一次性选取300个。关系建模关注“是否存在更合适的同实例代表”，同时区分相邻的不同实例。邻域用于比较，不直接把多个目标的特征平均成一个 query。
4. **证据复用与构建。** 选中后继续使用同一 z_i，残差更新原语义内容和初始参考框：`q_i = f_i + Δq(f_i, z_i)`，`b_i' = Refine(b_i, z_i)`。保留原语义信息，初始化残差从零开始，避免一开始破坏原检测路径。
5. **G5精修。** 将构建后的内容和参考框交给原六层 G5。初始边界证据进入 query 内容，后续 query 再调制 G5 的候选边证据，形成从初始化到精修的信息联系。首版保留 G5 的执行时序；初始化参考与首层固定 FDR 参考不同，不直接搬用两者的分布 logits。

## 3. 训练监督

- **目标存在与代表性分开。** 新增存在监督允许同一 GT 的多个有效候选为正；代表性监督通过候选池内的一对一分配鼓励每个 GT 获得一个合适代表。未被选为代表，不等于该候选没有目标信息。
- **关系监督。** 另行建立多候选与 GT 的关联，学习同实例竞争与邻近不同实例的区分；一对一匹配本身不能提供所有重复候选的归属。歧义样本不强行标注，不能仅按空间距离或 IoU 合并实例。按 GT 平衡监督，避免候选数量多的大目标主导训练。
- **筛选器独立获得梯度。** 在整个候选池上计算辅助监督，不能只依赖选中300个之后的 decoder 损失；硬 Top-K 本身不提供选择索引的梯度。内容与参考框修正接受定位/检测监督，明确处理原初始化路径的 detach。
- **保留 G5 训练设定。** DDF=0，保留 FGL、原检测和 DN 监督。后期可靠 G5 边界结果可作为后续辅助对齐信号，但不是首版必需条件，也不能替代候选池上的直接监督；GT 仅用于训练与离线分析。

## 4. 与 G5 的统一关系

统一主线是：**用边界证据区分实例、构建目标假设，再持续精修边界。** 筛选回答“哪些实例值得占用 query 名额”，构建回答“以什么内容和几何状态进入 decoder”，G5 回答“如何将这些实例定位得更准确”。

关键联系是边界描述在筛选与构建之间的实际复用，以及构建后的 query 对 G5 精修的作用；不预设所有阶段共享参数。学习式关系筛选本身不能单独作为创新结论，需证明边界证据及其跨阶段传递带来独立价值。

## 5. 最小消融与评价

各组均保留 G5 和300个 decoder query，同一基座内保持数据、初始化、训练预算、DDF及评测权重策略一致。

| 组别 | 学习式筛选 | 边界证据构建 | 回答的问题 |
|---|---|---|---|
| G5基线 | 关闭，原Top300 | 关闭 | 原有性能 |
| 仅筛选 | 开启 | 关闭 | 名额分配的收益 |
| 仅构建 | 关闭，原Top300 | 开启 | 内容与初始几何的收益 |
| 完整方案 | 开启 | 开启 | 两者联合效果 |

报告 AP、APsmall、AP75、召回及实测开销；同时记录预筛候选池和最终300个的 GT 覆盖、一对一匹配容量、重复候选程度及最终新增/丢失检测。按输入尺度和拥挤程度分析，不把几何覆盖等同于实例归属或最终检出。后续以去掉边界描述、仅保留语义/几何关系的对照，检验边界证据本身的价值。

## 6. 计算预算与轻量化约束

**低额外开销是方案的设计约束。** 统一的是边界证据的使用，初始化阶段采用轻量预览，精细分布修正由原 G5 完成；不固定采用5×3或其他特定采样布局。

- **控制处理规模。** M 是已有 encoder 候选池中接受边界处理的候选数，不是新增 decoder query。候选池大小、采样密度、特征维度和邻居数量联合控制，同时检查预筛对弱目标覆盖的影响。
- **一次提取，多处使用。** 新模块尽量共享特征投影并批量采样；筛选和 query 构建复用同一份边界描述。关系计算限制在局部邻域，邻居查找也需计入成本，避免隐含的全候选两两计算。
- **完整核算新增成本。** 前置粗框预测、边界采集与编码、关系评分及内容/参考框更新均可能增加开销；最终仍有300个 query 不代表这些计算免费。训练还需计入候选关联、辅助监督及反向传播；后期 G5 辅助信号优先复用已有前向结果。
- **以实测决定规模。** 在相同硬件、输入和 batch 条件下，相对 G5 基线记录推理时延、训练步耗时和峰值显存，参数量与 FLOPs 作为补充。不能将采样点数比例直接当作耗时比例。完整训练前先确认新增开销可接受，超预算时优先简化预览与关系模块。

## 7. 主要边界与实施决策

- 预筛过窄会限制弱目标召回；粗框偏差、模糊边界可能使证据读取偏向邻居。学习评分不保证严格每实例一个 query，需重点检查密集小目标是否被误合并。
- 不把边界响应强或分布低熵直接当作目标可靠性的充分条件，也不将一次几何覆盖或局部成功案例解释成整体收益。
- 实施前确定 M、邻居数、采样密度、GT关联规则、分数融合及辅助损失权重，以候选覆盖和计算预算约束设计。当前只形成研究方案，不承诺收益或完整文献范围内的新颖性。
