# 全层二维边界带：MLP 的 log 概率输入消融

## 目的与对照

作业 15509 的二维带全量版本没有改变 MLP 输入，仍将候选特征、query、边标识、相对边界偏移和原始 log 概率一起输入评分网络。其最佳结果为 AP 60.7504、AP75 66.7188、小目标 AP 59.8611，实际日志 epoch 76。

本轮检验：删除 MLP 对原始 log 概率的直接读取，是否有利于利用边界视觉信息预测修正量。这个假设尚未由前一轮结果证实。

## 唯一结构改动

新增 `use_log_prior` 开关，默认 `True`，保持旧配置和权重形状兼容；本轮配置设为 `False`。

| 部分 | 对照 15509 | 本轮 |
| --- | --- | --- |
| MLP 输入 | 候选特征 64 + query 64 + 边标识 8 + 偏移 1 + log 概率 1 | 候选特征 64 + query 64 + 边标识 8 + 偏移 1 |
| 输入维度 | 138 | 137 |
| 概率更新 | 原 logits + MLP 修正量 | 保持原 logits + MLP 修正量 |
| 边界采样及编码 | `5×7`、法向 ±8 输入像素、depthwise `3×3` + pointwise `1×1` | 保持一致 |
| 反馈 | 六层独立修正、完整候选分布积分并传给下一层 | 保持一致 |

没有去掉原分布，也没有把原 logits 清零。关闭开关只切断 MLP 对 `log_softmax(prior)` 的直接输入；query、当前框与后续层仍可能间接受原分布影响。第一层线性权重每个头减少 64 个参数，六个头合计减少 384 个参数。

## 全量训练设置

继承 `dfine_hgnetv2_l_uavswarm_all_layer_band2d_full.yml`：80 epoch、8 GPU、全局 batch 64、seed 0，保持数据、增强、多尺度、EMA、原生损失、梯度检查点及阶段切换逻辑。

仅加载 `weight/hgnetv2/PPHGNetV2_B4_stage1.pth`，encoder、decoder 和新分支重新初始化，不加载强 B0、15509 或短程权重。已有阶段切换 barrier 保留；本次不同时调整原回载策略或 epoch 计数逻辑，保持训练条件可比。

比较本轮与 15509 的最佳及末轮 AP、AP75、小目标 AP，并结合相同阶段的走势判断；单次种子消融不能给出统计显著性结论。
